    How it works

    1. Embed

    <iframe src="https://stream.eagle3dstreaming.com/v5/<owner>/<App>/<config>"
        allow="fullscreen; autoplay" allowfullscreen></iframe>

    2. Page → Unity

    iframe.contentWindow.postMessage(JSON.stringify({
  cmd: "sendDataToUE",
  value: { action: "setColor", value: "#ff5a36" }
}), "*");

    3. Unity → page

    // C#, in the Unity app (E3dsPageChannel.cs)
channel.SendToPage("{\"cmd\":\"unity.objectClicked\"}");

// JavaScript, on this page
window.addEventListener("message", e => { /* e.data */ });

    The Unity side is one C# file, E3dsPageChannel.cs, in unity/unity-project of this repository. Source of this page: unity/unity-demo.js.
