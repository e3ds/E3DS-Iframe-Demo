# E3DS Iframe Demo

**E3DS-Iframe-Demo** is a demonstration project that shows how to embed an **Unreal Engine Pixel Streaming** application inside a web page using an `<iframe>`, and how to exchange **real-time, two-way messages** between the webpage and Unreal Engine using **Eagle 3D Streaming’s messaging system**.

This project is ideal for developers who want to integrate interactive Unreal Engine experiences into websites, dashboards, or web applications.

---

## Features

- Embed Unreal Engine Pixel Streaming apps using an `<iframe>`
- Customize loading screens and UI states
- Full **two-way communication** between the webpage and Unreal Engine
- Messaging-based event handling and app control
- Demonstrates Eagle 3D Streaming iframe lifecycle stages
